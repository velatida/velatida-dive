# Velatida Dive

Proyecto práctico de Administración de Sistemas Informáticos en Red, desarrollado alrededor de la infraestructura ficticia de un centro de buceo.

-----------

# Obejetivos

- Administrar sistemas Linux.
- Gestionar usuarios, grupos y permisos.
- Configurar y administrar servicios.
- Trabajar con redes y comunicación entre sistemas.
- Crear scripts de automatización con Bash.
- Implementar copias de seguridad.
- Trabajar con Docker y Docker Compose.
- Incorporar monitorización.
- Documentar la infraestructura y las configuraciones.
- Utilizar Git y GitHub para el control de versiones.

-----------

# Infraestructura

El laboratorio está compuesto por dos máquinas virtuales Linux:

- dive-server — servidor principal.
- dive-client — máquina cliente para realizar pruebas y acceder a los servicios.
